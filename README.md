#  Hospital Data Analysis Dashboard

##  Project Overview

This project is an Excel-based Hospital Data Analysis Dashboard created to analyze and visualize hospital data.
The dashboard provides a clear overview of patient activity, department performance, billing amounts, visit types, payment methods, and monthly patient trends.
## Dashboard Features
- Total Patients by Department
- Total Bill Amount by Department
- Patients by Visit Type
- Bill Amount by Payment Method
- Monthly Patient Analysis
- Bill Amount by Visit Type
- Interactive Gender Filter
- Data Visualization using Charts
## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers / Filters
- Data Analysis
- Data Visualization
##  Key Insights
- Cardiology has the highest displayed patient count with 30 patients.
- Cardiology has the highest displayed departmental bill amount.
- OPD represents the largest displayed visit type at 65%.
- Cash represents the largest displayed payment-method share at 54%.
- The dashboard shows 78 patients in September and 47 patients in October.
##  Project Purpose
The purpose of this project is to practice data analysis and dashboard development using Microsoft Excel and to transform hospital data into meaningful visual insights.
